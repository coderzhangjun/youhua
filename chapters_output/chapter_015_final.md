# 第十五章 骨骼版

## Task A — 章节骨骼化

**剧情转折句：**
- 皇帝向主角介绍「玉面琴剑录事郎」罗琼岳，暗示念蕾明年参加「瑶台双栖凤求凰」时罗琼岳将是她的男伴。
- 皇帝告知主角正夫大防关乎家运国脉（天璇守望传来的天意）。
- 主角担心念蕾会在蓝颜情事会上被罗琼岳夺取芳心。

**情色相关保留：**
- [情色锚点] 皇帝描述「瑶台双栖凤求凰」中的夜明绡羞垫床、四种催情香（忘情香、动情香、迷情香、痴情香）。
- [情色前置] 主角为念蕾选择「动情香」，眼角湿润。
- 钱大监回忆主角母亲在瑶台院中献出元阴给浮华世家子。

**删除：**
- 皇帝与主角讨论正夫大防的法规细节（约15行）
- 主角与罗琼岳对话中的政治内容（约20行）

## Task B — 色情场景扩写

本章无实际交合场景。但「瑶台双栖凤求凰」的情色氛围描写保留。

主角为念蕾选了动情香，眼角湿润。想到念蕾还有四个月就要参加蓝颜情事会，与她仰慕的偶像罗琼岳肌肤相亲——他心里一阵酸，一阵痛，又一阵莫名的亢奋。

「瑶台双栖凤求凰」中的夜明绡羞垫床，一张就值20金铢。鲛绡帷帐轻盈如雾，羞垫中的催情香会被体温激活。五分之一的女子会在那张床上献出元阴。

主角的母亲，就是在那里把元阴给了一个浮华世家子，从此父亲心碎一生。
